# Сайт школы №117 имени Ч. Айтматова

Визуальный стиль: премиальный университетский — глубокий сине-графитовый, тёплый золотой и светлый каменный оттенки.

Статический сайт на HTML/CSS/JavaScript для GitHub Pages. Форма обращений передаёт сообщения в Telegram через Cloudflare Worker. Токен Telegram хранится только в секретах Worker.

## Структура

- `index.html` — страницы и контент сайта
- `styles.css` — адаптивный дизайн
- `script.js` — меню и отправка формы
- `worker.js` — серверная часть для безопасной отправки сообщений в Telegram

## 1. Создайте Telegram-бота

1. Откройте Telegram и найдите `@BotFather`.
2. Отправьте `/newbot`, задайте имя и username.
3. Сохраните выданный токен. Никому его не отправляйте и не публикуйте в GitHub.
4. Откройте своего нового бота и нажмите Start.
5. Чтобы получить личный ID, отправьте своему боту любое сообщение в личном чате. Откройте в браузере `https://api.telegram.org/botTOKEN/getUpdates`, заменив `TOKEN` локально на новый токен. В ответе найдите `message` → `chat` → `id`. Это значение для `TELEGRAM_PERSONAL_CHAT_ID`.
6. Создайте группу администрации и добавьте туда бота `@School117S_bot`. Отправьте в группе команду `/start@School117S_bot` или обычное сообщение. Снова откройте `getUpdates` и найдите обновление из группы: `message` → `chat` → `id`. ID группы обычно отрицательный; это значение для `TELEGRAM_ADMIN_GROUP_ID`.
7. Если `getUpdates` возвращает пустой список, отправьте новое сообщение после запуска бота и обновите страницу. Не публикуйте ссылку с токеном и не пересылайте её другим людям.

## 2. Опубликуйте Telegram Worker на Cloudflare

1. Создайте бесплатный аккаунт на https://dash.cloudflare.com/
2. Откройте **Workers & Pages** → **Create** → **Create Worker**.
3. Назовите Worker, например `school117-telegram`.
4. Откройте Quick Edit / Edit Code, удалите пример и вставьте содержимое файла `worker.js`.
5. Нажмите Deploy.
6. В настройках Worker откройте **Settings → Variables and Secrets** и добавьте:
   - `TELEGRAM_BOT_TOKEN` — тип Secret, новый токен от BotFather.
   - `TELEGRAM_PERSONAL_CHAT_ID` — ID твоего личного чата с ботом.
   - `TELEGRAM_ADMIN_GROUP_ID` — ID группы администрации.
   - `ALLOWED_ORIGIN` — обычная переменная, точный адрес опубликованного сайта, например `https://USERNAME.github.io`.
7. Сохраните изменения и выполните Deploy, если панель попросит.

Если сайт опубликован в проектном репозитории, адрес обычно имеет вид `https://USERNAME.github.io/REPOSITORY/`. Для `ALLOWED_ORIGIN` укажите только origin без `/REPOSITORY/`, например `https://USERNAME.github.io`.

## 3. Подключите Worker к сайту

Откройте `script.js` и замените строку:

`const TELEGRAM_ENDPOINT = "https://YOUR-WORKER-NAME.YOUR-SUBDOMAIN.workers.dev";`

на реальный URL Worker, который выдал Cloudflare, например:

`const TELEGRAM_ENDPOINT = "https://school117-telegram.example-account.workers.dev";`

Сохраните файл.

## 4. Опубликуйте сайт через GitHub Pages

1. Создайте новый публичный репозиторий на https://github.com/ (например, `school117`).
2. Загрузите в корень репозитория `index.html`, `styles.css`, `script.js` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
6. Через несколько минут GitHub покажет адрес сайта в разделе Pages.

`worker.js` можно хранить в репозитории, но секреты в него не добавляйте. Секреты должны оставаться только в настройках Cloudflare.

## 5. Проверьте работу

1. Откройте опубликованный сайт по HTTPS.
2. Заполните тестовую заявку и отправьте форму.
3. Проверьте, что сообщение пришло в Telegram.
4. Проверьте, что тестовая заявка пришла и в личный чат, и в группу администрации.
5. Если не пришло — проверьте URL Worker в `script.js`, `ALLOWED_ORIGIN`, токен и оба ID в настройках Cloudflare. Убедитесь, что бот добавлен в группу и ему разрешено отправлять сообщения.

## Важные замечания

- GitHub Pages — статический хостинг. Он не запускает серверный код и не хранит секреты.
- Cloudflare Worker выполняет роль серверного обработчика формы. У бесплатных платформ есть лимиты и условия, поэтому абсолютную работу «вечно» гарантировать нельзя.
- Фото в шаблоне загружаются с Unsplash и требуют интернет-соединения. Это иллюстративные изображения, не подтверждённые фотографии именно школы №117.
- Статистика и сведения о школе взяты из информации, предоставленной заказчиком. Перед официальной публикацией директору/администрации следует проверить актуальность данных, адресов, инфраструктуры и формулировок.
- Это шаблон сайта и канал связи, а не официальный сайт, одобренный школой. Публикуйте его от имени учреждения только с разрешения администрации.
- Не собирайте через форму чувствительные сведения о детях. Добавьте ссылку на утверждённую политику конфиденциальности перед публичным запуском.
